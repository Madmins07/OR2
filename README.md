The repository "OR2" contains our solution to the IM21204 Operations Research-II retest assignment. The project focuses on multi-objective optimization for efficient baggage packing, comparing Dynamic Programming (DP) and Integer Programming (IP) approaches. We've implemented a Python-based optimization system that helps users determine optimal item placement across cabin baggage, check-in baggage, and packers/movers services. The solution considers multiple constraints including weight/volume limits, item compatibility, and cost factors. The repository includes our implementation code, mathematical formulations in LaTeX, analysis of algorithm performance, and a deployed Streamlit web application that provides an interactive interface for users to input their own items and constraints. Try our solution live at: https://uditangshu-or2-app-hjvctt.streamlit.app/. Our comparative analysis demonstrates the tradeoffs between the DP and IP approaches in terms of solution quality and computational efficiency
